# شحناتي — نسخة الويب

1. ارفع محتوى المجلد ده (كله) على مستودع GitHub جديد.
2. في Vercel: Add New → Project → اختار المستودع → Deploy (من غير أي إعدادات).
3. من Settings → Environment Variables ضيف:
   - APP_PASSWORD = كلمة سر طويلة (دي اللي بتفتح بيها الموقع)
   - APP_SECRET = أي نص عشوائي طويل
4. Deployments → Redeploy.
5. افتح اللينك من Safari على الآيفون → مشاركة → "إضافة إلى الشاشة الرئيسية".

## المزامنة (عشان اللي يحصل في الموبايل يحصل في الموقع)
6. في Vercel: **Storage ← Create Database ← Upstash (Redis)** ← اربطها بالمشروع (Connect Project). ده بيضيف المتغيرات لوحده.
7. اعمل **Redeploy**.
8. في تطبيق الأندرويد (نسخة 3.9): **المزيد ← المزامنة بين الموبايل والموقع** ← اكتب لينك الموقع وكلمة السر ← **تفعيل ومزامنة**.
